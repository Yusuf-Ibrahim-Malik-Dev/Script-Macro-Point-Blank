# 🎯 Point Blank - Multi Mode Controller

AutoHotkey v1 script untuk Point Blank dengan **3 mode utama**:
- **AWP** — Fast Scope + Quick Change
- **SG** — Quick Change Shotgun
- **RECOIL** — Auto Tap Extra Fast

Dilengkapi sistem **mode switching**, **stop sementara**, dan **anti-boncos timing**.

## ✨ Fitur

- ✅ **3 Mode dalam 1 Script** — AWP, SG, RECOIL
- ✅ **Mode Switching** — Ganti mode tanpa restart script
- ✅ **Stop Sementara** — F5 untuk pause, F8 untuk lanjut
- ✅ **Anti-Boncos Timing** — Delay di-tuning khusus untuk PB
- ✅ **Quick Change Combo** — Q → 3 → 1 → 1 (SG), Q → 3 → 1 (AWP)
- ✅ **Auto Tap Extra Fast** — RECOIL dengan break condition responsif
- ✅ **Status Notifikasi** — ToolTip + SoundBeep tiap ganti mode

---

## ⌨️ Hotkey

| Tombol | Fungsi |
|--------|--------|
| **F5** | STOP sementara |
| **F6** | Mode AWP (Fast Scope + QC) |
| **F7** | Mode SG (Quick Change) |
| **F8** | Mode RECOIL (Auto Tap) |
| **F1** | KELUAR dari script |
| **Klik Kiri** | Trigger mode yang aktif |
